⚡ QUICK START (3 STEPS)
================================================================================

STEP 1: Install Python Dependencies
------------------------------------
Open terminal/command prompt in this folder and run:

    pip install -r requirements.txt

This installs Flask, pandas, scikit-learn, etc.


STEP 2: Copy Your Model Files
------------------------------
1. Run your Jupyter notebook to generate 4 pkl files
2. Copy ALL pkl files to the "models/" folder
3. Make sure folder looks like:
   models/
   ├── logistic_default_model.pkl
   ├── random_forest_churn_model.pkl
   ├── kmeans_segmentation_model.pkl
   └── linear_regression_profit_model.pkl
   (+ all the scaler and feature files)


STEP 3: Run the Application
----------------------------
In the same terminal, run:

    python app.py

You should see:
    ✓ All models loaded successfully!
    Server running on: http://127.0.0.1:5000

Then open your browser and go to:

    http://127.0.0.1:5000

================================================================================
❌ TROUBLESHOOTING
================================================================================

ERROR: "Models not loaded"
→ Check models/ folder has all 4 pkl files
→ Verify file names match exactly (case-sensitive)

ERROR: "No module named 'flask'"
→ Run: pip install -r requirements.txt

ERROR: "Port 5000 already in use"
→ Another app is using port 5000
→ Either close that app or change port in app.py

ERROR: Form not loading
→ Check browser console (F12 → Console tab)
→ Verify Flask server is running
→ Try http://127.0.0.1:5000 (with http://)

ERROR: Predictions return "-"
→ Check Flask terminal for error messages
→ Verify all pkl files exist in models/
→ Check feature names match model training
